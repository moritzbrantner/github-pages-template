# GitHub Pages Template

Canonical GitHub Pages foundation for Moritz Brantner's repositories.

This repository owns the shared presentation layer for project Pages sites: navigation, evidence and stats views, provenance display, responsive/accessibility behavior, and the static generator used by consuming repositories. Deployment remains owned by `moritzbrantner/reusable-workflows`; evidence semantics remain owned by their producing tools such as `coding-tooling`, Moonlight, runtime-profiler, and Unlighthouse.
